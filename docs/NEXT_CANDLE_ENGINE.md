## ১. স্ট্র্যাটেজি — একটাই, এবং সেটাই যথেষ্ট

**প্রশ্ন:** নতুন ক্যান্ডেল শুরু হওয়ার ০ সেকেন্ডে, আগের বন্ধ হওয়া ক্যান্ডেলগুলো
দেখে বলা যায় কি — এই নতুন ক্যান্ডেল **GREEN (CALL)** হবে না **RED (PUT)**?

**উত্তর দেয়:** একটি regularized logistic regression — ৩৪টি feature, যেগুলো
শুধুমাত্র **আগের বন্ধ হওয়া ক্যান্ডেল** থেকে তৈরি (কোনো look-ahead নেই):

| গ্রুপ | Feature | বাংলা ব্যাখ্যা |
|---|---|---|
| ক্যান্ডেল অ্যানাটমি | `body1/2/3`, `body_decay`, `wick_imb1/3`, `clv1`, `range1_atr` | বডির সাইজ-মোমেন্টাম, উইক রিজেকশন, ক্লোজ ক্যান্ডেলের কোথায় হলো |
| সিকোয়েন্স (user-এর "কোন ক্যান্ডেলের পরে কোনটি আসে") | `last_color`, `streak`, `same2`, `pat_ggg…pat_rrr`, `patt2_prob`, `patt3_prob` | রঙের ধারা, ২/৩-ক্যান্ডেল প্যাটার্ন, আর **প্যাটার্নের পরে ঐতিহাসিকভাবে কত % সবুজ এসেছে** (এই পেয়ারের নিজের ডেটা থেকে, causal কাউন্ট) |
| প্রেসার | `press3`, `press10_z` | শেষ ৩/১০ ক্যান্ডেলের নেট বাই-সেল চাপ (z-score) |
| কনটেক্সট | `range_pos`, `stretch50`, `ret5/20/60`, `ema_gap`, `htf5_gap`, `atr_ratio`, `hour_sin/cos` | রেঞ্জে অবস্থান, ট্রেন্ড টিল্ট (1m + 5m HTF), ভোলাটিলিটি রেজিম, দিনের সময় |

**তিন স্তরের মডেল (সব এক ইঞ্জিনের ভেতরে):**

1. **GLOBAL PRIOR** — ৪টি রিয়েল মার্কেটে (BTC/ETH/XRP/BNB 1m, ~36k ক্যান্ডেল)
   pooled-trained weights (`core/next_candle_weights.json`) — প্রথম ক্যান্ডেল
   থেকেই সামঞ্জস্যপূর্ণ ভবিষ্যদ্বাণী দেয়।
2. **LOCAL ADAPTATION** — একই মডেল প্রতি পেয়ারে **নিজের ক্যান্ডেলে অনলাইনে রিফিট**
   হয় (trailing 5000, প্রতি ৫০ ক্যান্ডেলে)। গবেষণায় প্রমাণিত: frozen weights
   mean-reverting feed-এ ৩৫-৪০% পায় (মানে উল্টো রেজিমে বিপর্যয়), আর
   adapted মডেল ৬৬-৭১% — **ইঞ্জিন প্রতি ফিডে নিজে শেখে কোন ক্যান্ডেলের পরে
   কোনটি আসে।**
3. **CALIBRATED BLEND** — `p = w·p_local + (1−w)·p_global`, `w = n/(n+3000)`;
   ডিসপ্লে-সম্ভাবনা shrink করা (slope 0.636) — **স্ক্রিনে ৬০% মানে সত্যিকারের
   ~৬০%।**

**কনফিডেন্স ব্যান্ড (backtest-validated):** যত বেশি কনফিডেন্স, তত বেশি
নির্ভুলতা — BTC-তে 55+ ব্যান্ডে ৫৬.৮%, 58+ ব্যান্ডে ৬০.৮% (নিচের টেবিল)।

## ২. সিগন্যাল প্রেডিকশন সিকোয়েন্স পাইপলাইন

```
টিক (ms) ──► রানিং ক্যান্ডেল (broadcast: chart, live_pred, tick_eye)
   │
   ▼  ক্যান্ডেল বন্ধ (T+60s boundary)
_close_running_and_start_new()
   ├─ ① engine.ingest(closed)          ← CSE: গ্রেডিং + ট্রেইনিং + নতুন প্রেডিকশন
   │      ├─ আগের প্রেডিকশন গ্রেড (এই ক্যান্ডেলের জন্য ছিল কি না)
   │      ├─ pending training row-এর target resolve
   │      ├─ rolling state update (ATR/EMA/প্যাটার্ন-কাউন্ট/HTF…)
   │      ├─ (প্রতি ৫০ ক্যান্ডেলে) local model refit — to_thread, ~0.2s
   │      └─ ★ ০-সেকেন্ড প্রেডিকশন: পরের (এখন শুরু হওয়া) ক্যান্ডেলের রঙ — LOCKED
   ├─ ② _grade_and_log()               ← DB-তে সিগন্যাল রেকর্ড + গ্রেড
   └─ ③ _run_eoc()
          └─ CSE পেলোড → স্ট্যান্ডার্ড সিগন্যাল রেজাল্ট (signal_source="next_candle")
                ├─ stream.prediction = রেজাল্ট (direction ০ সেকেন্ডে লকড)
                ├─ tick broadcast → msg.prediction.next_candle (UI প্যানেল)
                └─ /api/next-candle/{asset} (prediction + লাইভ স্ট্যাটস)
   │
   ▼  পরের ক্যান্ডেল বন্ধ → আবার ① → প্রতি ক্যান্ডেলে সৎ গ্রেডিং-লুপ
```

**গুরুত্বপূর্ণ নিয়ম:**
- প্রেডিকশন **ক্যান্ডেল শুরুর ০ সেকেন্ডে লক হয়** — মাঝপথে CALL↔PUT বদলায় না।
- শুধুমাত্র বন্ধ হওয়া ক্যান্ডেল দেখে প্রেডিক্ট করে — রানিং ক্যান্ডেলের টিক
  প্রেডিকশন বদলায় না (আলাদা "রানিং ক্যান্ডেল প্রেডিকশন" প্যানেলে লাইভ
  চাপ-স্ট্যাটাস দেখায়, সিগন্যাল নয়)।
- ডোজি (open==close) কাউন্ট হয় না (binary trade-এ জেতা/হারা কোনোটাই নয়)।
- গ্রেডিং ইঞ্জিন নিজেই করে — প্রতি পেয়ারে rolling accuracy, last-20,
  max wrong streak → UI + API-তে সৎ সংখ্যা।

**ডেমো মোড (QX_DEMO_FEED=1):** ডেমো জেনারেটর এখন MR+trend রেজিম-সহ
OTC-সদৃশ dynamics ব্যবহার করে — ডিপ-সিডের (৩০০০ ক্যান্ডেল) পর রিপ্লে-গ্রেডেড
accuracy ~৭৩-৭৭% দেখা যায়; লাইভ ক্যান্ডেল বন্ধ হওয়ার সাথে সাথে আরও সৎ
সংখ্যা জমে।

## ৫. সাইটম্যাপ (কোথায় কী)

| ফাইল | ভূমিকা |
|---|---|
| `core/next_candle.py` | ★ ইঞ্জিন — feature, model, blend, calibration, grading |

**Env:**
- `QX_NEXT_CANDLE=0` → পুরনো multi-strategy চেইনে rollback
- `QX_NC_SEED_CANDLES=3000` → ডিপ-সিড গভীরতা (300 = বন্ধ)
- `QX_NC_BLEND_K / QX_NC_WINDOW / QX_NC_REFIT / QX_NC_FIT_MIN` → টিউনিং (research defaults)

**গুরুত্বপূর্ণ সতর্কতা:** রিয়েল মার্কেট ১-মিনিটে কেউ ৯০%+ দিতে পারে না — যে
সিস্টেম দাবি করে সেটা ফিটেড/ফেক। এই ইঞ্জিনের রিয়েল-মার্কেট সৎ সংখ্যা ~৫২%
(p<1e-8), কাঠামো-সমৃদ্ধ (OTC-সদৃশ) ফিডে ৬৬-৭৭% — এবং সেটা **নিজে নিজের
গ্রেডিং-এ প্রমাণ করে**, প্রতি ক্যান্ডেলে।
