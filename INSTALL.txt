   Binary Signals App — Installation Guide (English summary)
═══════════════════════════════════════════════════════════════════════

QUICK START (English):
  1. Install Python 3.10–3.12 from https://www.python.org/downloads/
     (Check "Add Python to PATH" during install.)
  2. Install Git from https://git-scm.com/download/win (default options).
  3. Double-click install.bat  (one-time — downloads the app + deps).
  4. Double-click start.bat     (daily use — starts the server).

On first run, the script asks for your Quotex email + password and saves
them to .env. After that, the app auto-connects and opens the browser.

NOTE: Simulation mode (USE_SIM=1) was permanently disabled on 2026-07-25.
QX_TOKEN is required for live data — see RAILWAY_TOKEN_SETUP.md.

২. Git ইনস্টল করুন:

   • "Click here to download" ক্লিক করুন
   • ইনস্টল করুন (সব default অপশনে Next ক্লিক করুন)

১. এই folder-এ install.bat ফাইলে double-click করুন
২. অ্যাপ নিজে থেকে সব করবে:
   ✅ App download করবে
   ✅ Dependencies ইনস্টল করবে
   ✅ start.bat চালু করবে

  ✅ ব্রাউজার নিজে থেকে খুলবে (৫ সেকেন্ড পরে)
